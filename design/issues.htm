Add retry handling to GitHub API calls

enhancementarea: integrations
MC
mchenopened this issue 5 days ago

Some GitHub API requests fail transiently when we hit rate limits or intermittent network errors. The issue list and repository picker currently fail immediately, even when retrying would recover.

Expected behavior

  • Retry transient failures with a short exponential backoff.
  • Respect the API's retry-after guidance when it's available.
  • Show a useful error after the retry limit is reached.

Keep the retry count small so the local UI stays responsive.
